# currency-converter
Real-time currency converter web app supporting 160+ currencies with keyword search (country/code) and multi-language UI (Simplified Chinese, Traditional Chinese, English). Built with pure HTML/JS, ready for GitHub Pages.

實時貨幣換算器網頁應用，支援 160+ 種貨幣、支援國家/代碼關鍵字搜尋，以及多語言切換（繁體、簡體、英文）。純 HTML/JS 打造，完美支援 GitHub Pages 部署。

实时货币换算器网页应用，支持 160+ 种货币、支持国家/代码关键词搜索，以及多语言切换（简体、繁体、英文）。纯 HTML/JS 打造，完美支持 GitHub Pages 部署。

[繁體中文]

實時匯率自動更新：每次開啟網頁或切換幣別時，會自動從國際外匯 API 抓取最新市場數據，確保換算準確。

智慧國家/代碼搜尋：支援直接輸入國家名稱（如「台灣」、「日本」）或貨幣代碼（如 USD、JPY）來快速篩選。

多語言介面支援：右上角可隨時切換繁體中文、简体中文或英文。

一鍵互換與即時計算：輸入金額後立即顯示結果，並提供「⇅」按鈕快速對調來源與目標貨幣。

[简体中文]

实时汇率自动更新：每次打开网页或切换币别时，会自国际外汇 API 抓取最新市场数据，确保换算准确。

智能国家/代码搜索：支持直接输入国家名称（如“中国”、“日本”）或货币代码（如 USD、CNY）来快速筛选。

多语言界面支持：右上角可随时切换简体中文、繁体中文或英文。

一键互换与实时计算：输入金额后立即显示结果，并提供“⇅”按钮快速对调来源与目标货币。

[English]

Real-time Rates: Automatically fetches the latest market rates from the international exchange rate API upon loading or switching currencies.

Smart Keyword Search: Easily search and filter by country name (e.g., "USA", "Japan") or currency code (e.g., USD, EUR).

Multi-language Support: Switch seamlessly between Simplified Chinese, Traditional Chinese, and English via the top menu.

Instant Conversion & Swap: Instantly computes results as you type, with a convenient swap button (⇅) to reverse source and target currencies.
